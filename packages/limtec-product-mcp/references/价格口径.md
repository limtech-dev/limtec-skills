# 价格口径

## 来源

技能内的价格簿（`data/pricebook-limtec.js`、`pricebook-domestic.js`、`pricebook-cylinder.js`、`pricebook-rod.js`）与力姆泰克线上选型平台**逐字节同源**，为**线上公开参考价（含税口径）**。

## 规则

1. 对客户口径：一律说「公开参考价（含税），仅供参考，正式报价以力姆泰克书面确认为准」。
2. 报价表中 `unit_price: null` 的行 = 库内无公开价，显示「需询价」；`quote.missing` 汇总了全部待询价项。**不得估算、不得编造、不得把参考价说成合同价。**
3. 内部成本价、折扣体系、渠道价不在本技能内，也不允许通过任何方式注入。
4. PDF 方案书的价格区会自动带上述免责声明，无需手动添加。

## 常见问题

- **合计为「需询价」**：全部行都无价（如手动驱动、特殊配置），引导客户在线平台询价或联系销售。
- **部分行缺价**：主件有价、附件缺价时照常给合计，并明示缺价项。
