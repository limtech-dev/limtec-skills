# 参数对照（三条产品线）

> 全量字段与默认值以 `node scripts/select.js --product=<线> --list-fields` 的实时输出为准，本表只列常用项与口径提示。

## 通用约定

- 所有数值参数用 `--set=键=值` 传入；数组类字段（`accessories`、`special`、`servo_brand`）传单个值会自动包成数组。
- `stroke`／`speed`（推杆）与 `stroke_mm`／`speed_mm_s`（升降机、电缸）是不同键，别混用。
- **载荷单位是铁律**：`load` 的含义取决于 `load_unit`。LAP/LBP 默认 `t`（吨），LAM 默认 `kg`；升降机、电缸默认值见 `--list-fields`。用户说「10 吨」和「10 kN」必须分清。

## screwjack（螺旋升降机）

| 字段 | 说明 | 常用取值 |
|---|---|---|
| series | 系列 | `auto`（自动跨系列）/ SJA / SJB / KV / EHB / SCA / SCB |
| load / load_unit | 载荷及单位 | kN（也可 t、kgf、N） |
| load_pull | 拉力（有反向工况时） | 同上 |
| static_load | 静载（停机保持） | kN |
| stroke_mm | 行程 | mm |
| speed_mm_s | 速度 | mm/s |
| units | 台数 | 1~4+ |
| layout | 布置形式 | 如「H型布置」（联动布局图输出） |
| motion | 运动方向 | `S`（升降）等 |
| guide | 有无导向 | `有` / `无` |
| env | 环境 | `室内` / 户外 / 高温等 |
| sync | 同步方式 | `机械`（4 轴联箱）/ `电气`（电同步，电机数量 ×台数） |
| drive | 驱动 | `servo220` / `servo380` / `ac` / `hand`（手动） |
| servo_brand | 伺服品牌 | 数组（如西门子 V90/S200/S210） |
| cycles_per_day / hours_per_day / days_per_year | 工作制 | 影响寿命校核 |
| special / special_texts | 特殊要求 | 数组 |

## cylinder（电缸／电动缸）

| 字段 | 说明 | 常用取值 |
|---|---|---|
| series | 系列 | DMB / EMB / GTR / FMR |
| load / load_unit | 推力及单位 | t 或 kN |
| stroke_mm / speed_mm_s | 行程 / 速度 | mm / mm·s⁻¹ |
| input_form | 输入形式 | 如 `P10/P20` |
| install | 安装形式 | 如 `FF`（前法兰） |
| joint | 接头 | 如 `FM` |
| drive | 驱动 | `servo380` / `servo220` 等 |
| gtr_drive | GTR 系列专用驱动 | 选 GTR 时填 |
| servo_brand | 伺服品牌 | 如 `V90` |
| accessories | 附件 | 数组，如 `AR` |
| precision_mm | 定位精度 | mm |
| ip | 防护等级 | IP65 等 |

## rod（电动推杆）

| 字段 | 说明 | 常用取值 |
|---|---|---|
| series | 系列 | LAP / LBP / LAM / LBM |
| lam_group | LAM 档位 | 仅 LAM 需要（LAM6 等） |
| load / load_unit | 推力及单位 | LAP/LBP 默认 `t`；LAM 默认 `kg`；可切 kN/kgf/N |
| load_pull / static_load | 拉力 / 静载 | 各自独立单位键 |
| speed | 速度 | mm/s |
| stroke | 行程 | mm |
| drive | 驱动 | `ac3`（三相 AC）/ `ac1`（单相）/ `servo` 等 |
| limit_sw | 限位开关 | 有/无 |
| install / input_dir / joint | 安装 / 输入方向 / 接头 | 同线上平台 |
| accessories | 附件 | 数组 |

## 输出 JSON 结构（--json）

```
product / product_label / input / model / full_code / spec
checks[]      校核：{name, ok, val}
calc[]        计算摘要：[键, 值]
accessories[] 附件：{desc, qty}
quote         {rows:[{desc,spec,qty,unit_price}], total, missing[]}
warnings[] / layout_image / generated_at / link / price_note
```

`unit_price` 为 null 表示「需询价」，必须如实转述。
