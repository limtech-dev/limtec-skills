How it works

The engine and the price book are byte-identical to the Lim-Tec online selector — the skill is an offline wrapper, not a re-implementation.

  1. Describe the duty point. Load and stroke, or thrust and speed; unit count and layout (H / U) for multi-jack groups; drive type, environment and duty profile as needed.
  2. Let it size. The selector walks the same model library as the online tool: series, frame, motion type, mounting, joints and drive, and runs the thrust, stability, life and duty-cycle checks.
  3. Take the result. A readable report or structured JSON: the model, the complete order code with every option digit resolved, and a bill of materials with USD reference prices. Proposal PDF export is built in.

Install

Works with Claude Code, Claude Desktop (skills), and any agent host that can run a script.

# Claude Code — whole marketplace (gets updates)
/plugin marketplace add limtech-dev/limtec-skills
/plugin install limtec-product-selector@limtec

# or clone just this skill
git clone https://github.com/limtech-dev/limtec-skills.git

For claude.ai / Claude Desktop: download limtec-product-selector_en_v1.0.4.zip from the dist folder and upload it under Customize → Skills.
