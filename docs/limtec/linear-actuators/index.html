The series

Four actuator families cover the standard rod-type range from light damper duty to heavy door drives.

SeriesDriveTypical use
LAPAC motor (AC3) or servoGeneral-purpose push-pull duty
LBPAC motor (AC3) or servoHeavier frames in the same family
LAMAC or servoModular build-up — voltage, ends, angle, limit switch, signal, plug, cable and IP are each a selectable digit
LBMAC or servoCompanion frames to LAM

What the selector resolves

Every position of the order code is built by the engine — the same code paths as the online tool.

Frame & installation

Series and frame from thrust, stroke and speed; single motor flange (P3) and other installation forms; right- or left-hand input direction; ROE and other rod-end joints.

Limit switches

Standard (STD) or proximity (FCP) limit switches are resolved into the order code instead of being added by hand afterwards.

LAM build-up digits

The LAM family is a modular build-up: voltage, end forms, mounting angle, limit switch, signal, plug, cable and IP class are each a selectable digit — the engine assembles them for you.

Checks before a model is offered

Thrust, speed and power limits and stability are checked against the selected frame — and the load unit is echoed back explicitly (LAP/LBP work in tonnes, LAM in kilograms).

Drive & pricing

AC motor (AC3) or servo input; where no motor is wanted, the drive is excluded and the price covers the actuator only. USD reference prices for the whole bill of materials.

Proposal PDF

Export the selection as an English proposal PDF with layout, checks and pricing — ready to attach to a quotation.

One command, one answer

An LAP actuator pushing 10 kN through a 600 mm stroke at 50 mm/s, AC motor driven.

node scripts/select.js --product=rod \
  --set=series=LAP --set=load=10 --set=load_unit=kN \
  --set=speed=50 --set=stroke=600 --set=drive=ac3

The demo run resolves this to LAP56 with a total of USD 1,849 (reference prices). Add --json=result.json for structured output, or --list-fields to see every key for this product line.

Frequently asked

Is the engine the same as the online tool?

Yes. The selection engine and the price book are byte-identical to the Lim-Tec online selector (md5 list shipped in scripts/source_manifest.json). The skill is an offline wrapper, so an offline answer matches the online answer.

Are the prices official offers?

No. They are USD reference prices from the Lim-Tec price system, for evaluation and quoting support. Formal quotations come from Lim-Tec or its sales channels.

Which load unit does each series use?

LAP and LBP default to tonnes, LAM defaults to kilograms. The result always echoes the resolved unit back before you quote anything.

Does it need an internet connection?

No. The skill runs fully offline; only the initial download from GitHub needs a connection.
